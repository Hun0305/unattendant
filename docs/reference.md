# 시장 조사

Oct 5, 2026 · @hun

AI가 블로그를 쓰는 곳은 이미 많고, AI 운영을 공개하며 몇 달씩 버틴 곳도 있다. 비어 있는 자리는 **AI가 직접 실측해 정기적으로 글로 내고, 운영 지표를 상시 공개하는 한국어 블로그**다. 각 요소를 따로 하는 곳은 있지만, 모두 갖춘 곳은 찾지 못했다.

다섯 차례 웹 검색으로 조사했고, 4·5차는 서브에이전트가 수행했다. 5차에서 반례가 나오지 않아 조사를 마쳤다. 못 찾았다는 건 없다는 뜻이 아니고, 사례의 수치는 각 사이트나 기사가 밝힌 값이고 따로 검증하지 않았다.

## 결론과 포지셔닝

우리가 노릴 자리는 **찾아와서 쓸 만한 실측 데이터 + 상시 공개하는 운영 지표 + 한국어**다. AI 운영 공개와 장기 운영은 이미 있지만, 그것만으로는 독자가 모이지 않았다. 5차 조사에서도 반례가 나오지 않아 이 포지셔닝으로 확정한다.

| 영역 | 상태 | 근거 |
| --- | --- | --- |
| AI가 블로그 글을 쓴다 | 레드오션 | 수익형 자동 포스팅 툴, AI 콘텐츠 팜 3,749곳, 공개형 AI 블로그도 여럿. 일본·중국·한국도 같다 |
| AI 운영임을 공개한다 | 최소 조건 | 콘텐츠 팜을 가르는 기준 중 하나가 "AI 작성 미공개"다. Substack은 글의 AI 작성 비율 추정치를 표시하기 시작했다 |
| AI가 운영을 몇 달씩 공개한다 | 이미 있음, 독자는 적음 | ATLAS 117일째 구글 유입 월 50\~100명, FAMA 팔로워 2명, Andon FM 청취자 한 자릿수, Clavis 최다 조회 글 124뷰 |
| AI가 하드웨어에서 직접 측정해 공개한다 | 거의 비어 있음 | 에이전트가 관리하는 SBC 벤치마크 레포(Severus) 1곳뿐이다. 블로그가 아니고 스타 0이며, 정기적으로 글로 내는 곳은 없다 |
| 운영 신뢰성 지표(비용·개입·복구)를 공개한다 | 일회성만 있음 | Clavis·Uravation·aikatsulab이 회고로 한 번씩 공개했다. 상시 갱신되는 통합 지표 페이지는 없고, Andon FM은 수지에서 토큰 비용을 뺀다 |
| 한국어로 운영을 공개한다 | 거의 비어 있음 | 모두의AI가 "완전 자율 AI 에이전트가 운영"을 내걸었지만, 운영 과정과 지표는 공개하지 않는다 |

**역할 분담**: 메타 컨셉은 블로그의 정체성과 커뮤니티 공유용 이야기로 두고, 검색 유입은 Pi 실측 데이터가 맡는다.

**시간은 해자지만 충분조건은 아니다.** 같은 실험을 매달 다시 돌려 쌓은 시계열 데이터는 오래 운영할수록 따라오기 어렵다. 하지만 ATLAS처럼 117일을 버텨도 찾아와서 쓸 이유가 없으면 독자는 오지 않는다.

**배포는 사람의 몫이다.** ATLAS 스스로도 "자율성의 마지막 한 걸음은 사람"이라고 결론 내렸다. 커뮤니티 공유는 처음부터 사람이 맡는 것으로 설계한다.

**한국어 검색의 변수**: 네이버 AI 브리핑이 2025년 말 기준 통합검색 질의의 20%까지 확대됐고, 광고 수익이 40% 가까이 줄었다는 창작자 사례가 보도됐다([ZDNet, 2026-08-06](https://zdnet.co.kr/view/?no=20260805173711)). 클릭 유입보다 AI 요약에 인용되는 출처가 되는 것을 목표로 잡는다.

가로축은 누가 운영하는지, 세로축은 글의 재료가 어디서 오는지다. 오른쪽 위 칸에서 정기적으로 글을 내는 블로그는 찾지 못했다.

## 앞선 결론 점검

1\~4차 조사 결론 12개 중 4개를 정정하고, 1개는 표현을 고치고, 2개는 조건을 달았다. 정정은 3차(ATLAS·ALMA·Andon FM 발견)와 4차(Severus·모두의AI 발견)에서 나왔고, 5차에서는 정정할 반례가 없었다.

| 앞선 결론 | 판정 | 근거 |
| --- | --- | --- |
| "자기 운영을 숫자로 공개하는 곳은 없다" | 정정 | 3차: ATLAS, ALMA, FAMA, Andon FM, AI Village가 이미 공개한다 |
| "무인 운영 기록을 몇 달 단위로 공개하는 건 아무도 못 버틴 자리" | 정정 | 3차: ATLAS 117일, Andon FM 약 5개월, AI Village 1년 이상 |
| "AI가 하드웨어로 실험하는 곳은 없다" | 정정 | 4차: 에이전트 Severus가 관리하는 SBC 벤치마크 레포가 있다. 다만 블로그가 아니고, 실측을 에이전트가 직접 했는지는 불명이다 |
| "한국어로 AI 운영을 공개하는 곳은 없다" | 정정 | 4차: 모두의AI가 "완전 자율 AI 에이전트가 운영"을 내걸었다. 운영 과정과 지표는 공개하지 않는다 |
| "emptychair는 인증서 만료로 멈추다" | 표현 수정 | 연재가 1월에 멈추고 10/5 접속 때 인증서가 만료돼 있었다. 멈춘 원인은 확인하지 못했다 |
| "우리의 해자는 시간" | 부분 유효 | 시계열 데이터의 가치는 시간이 쌓일수록 커지지만, 시간만으로 독자가 오지는 않는다(ATLAS) |
| "운영 신뢰성 지표를 공개하는 곳은 거의 없다" | 부분 유효 | 4차: 일회성 공개는 여럿(Clavis, Uravation, aikatsulab)이다. 없는 건 상시 갱신되는 통합 지표 페이지다 |
| "AI가 블로그를 쓴다"는 레드오션 | 유효 | 4차: 일본·중국·한국도 같다 |
| AI 운영 공개는 최소 조건 | 유효 | NewsGuard 기준. 4차: Substack이 AI 작성 비율 추정치 표시를 시작했다 |
| 꾸준함 4원칙(연속성, 시계열, 신뢰 신호, 지루한 장애 감시) | 유효 | SE Ranking 16개월 데이터에서도 순위는 회복되지 않았고, 원인은 차별성과 신뢰 신호였다 |
| 엘리펀트컴퍼니: AI 글은 노출 3배, 완독률은 낮다 | 유효 | 다만 3개 주제를 비교한 작은 실험이다 |
| 실측 데이터 + 운영 지표 + 한국어, 실측 데이터가 유입 담당 | 유효 | 4차로 범위를 좁혔다: AI가 실측해 정기 발행하고 운영 지표를 상시 공개하는 한국어 블로그 |

## 설계에 반영할 조정안

아래 9개는 조사에서 나온 변경안이고, 2026-10-05에 설계 탭에 모두 반영했다. 괄호는 반영한 설계 탭의 위치다.

- [x] **역할 분담**: 메타 컨셉은 정체성·공유용, Pi 실측 데이터는 검색 유입 담당 (개요)
- [x] **발행 목표**: 주 3개(실험 1, 메타 1, 주간 보고서 1). 하루 최대 1개 상한은 유지 (운영 사이클)
- [x] **월간 재측정**: 같은 실험을 매달 다시 돌려 시계열로 쌓고, 원본 CSV와 측정 방법을 공개 (운영 사이클의 월간 루프, `schedule_experiment` 반복 주기)
- [x] **상태 띠**: 모든 페이지 상단에 연속 무인 운영일, CPU 온도, 오늘 비용 표시. Low-tech Magazine의 배터리 표시를 참고 (관측성의 대시보드)
- [x] **지루한 장애 헬스체크**: 도메인 만료일과 갱신 결제 수단, API 잔액, 디스크 용량, 터널 연결 (일간 루프의 상태 점검, `get_system_health`)
